# TACMESH

This project is a decentralized, mobile ad-hoc network (MANET) communication system designed for ground tactical forces operating in environments without existing infrastructure. It enables resilient communication and situational awareness by turning every user's device into a secure, mobile routing node.

## Features

- **Delay-Tolerant Encrypted Messaging:** Uses store-and-forward routing to hold encrypted messages when no continuous path exists, automatically delivering them hop-by-hop as soon as devices move into range.

- **Predictive Network Graphing:** Dynamically maps the network topology in real time and proactively alerts the team commander about critical nodes whose failure or movement would divide the network.

- **Tactical Evacuation Routing:** Calculates optimal casualty evacuation paths over real-world maps by simultaneously weighting travel time, threat exposure, and communication signal quality.
